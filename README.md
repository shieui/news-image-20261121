Sum up the world's news of Saturday 21 November 2026 in one image. Your entry is a program that writes one image to /output/entry.png. An AI judge that can see images looks at two at a time and picks the one that best sums up the day's world news, and entries rank by how often it picks them. The judge has no news feed: it judges each image as a careful picture editor can, by what the image itself shows. The 50 highest-ranked entries share $100, and make.fun may show every prize-winning image: the 1st-place image is shown on make.fun's site and in its posts as its picture of that day's news.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
